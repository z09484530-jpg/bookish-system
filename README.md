# VIBE FY — музыкалык колдонмо

## Иштетүү

```bash
npm install
npm run dev
```

Ач: http://localhost:5173

1. **Поиск** → ырды изде (мисалы Drake)
2. Карточкадагы **▶** бас
3. Төмөндө Spotify player чыгат → **Play** бас → ыр угулат

## Деплой (Vercel)

```bash
npx vercel --prod
```

## Деплой (Netlify)

```bash
npm run build
npx netlify deploy --prod --dir=dist
```
